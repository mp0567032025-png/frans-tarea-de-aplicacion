# Mi organizador de tareas — Proyecto sumativo

Aplicación web sencilla creada con HTML, CSS y JavaScript para practicar la manipulación del DOM y los eventos.

## Funciones
- Agregar tareas.
- Marcar tareas como completadas.
- Eliminar una tarea individual.
- Eliminar todas las tareas completadas.
- Ver el número de tareas pendientes.
- Diseño adaptable a móviles y computadoras.

## Cómo ejecutar
1. Descarga o clona esta carpeta.
2. Abre `index.html` en un navegador moderno.
3. También puedes abrir la carpeta en Visual Studio Code y usar una extensión como Live Server.

No requiere instalación de paquetes ni servidor.

## Cómo trabajar con OpenCode
1. Instala y abre OpenCode en la carpeta del proyecto.
2. Puedes pedirle que revise el código, explique funciones o proponga mejoras.
3. Revisa los cambios y prueba la aplicación en el navegador antes de entregar.

## Publicar en GitHub para entregar el enlace
Desde una terminal abierta en esta carpeta, ejecuta:

```bash
git init
git add .
git commit -m "Crear organizador de tareas"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
```

Crea primero un repositorio vacío en GitHub y reemplaza la URL de ejemplo por la URL real de tu repositorio. Después entrega el enlace del repositorio al docente.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño visual; las reglas y declaraciones están comentadas línea por línea.
- `app.js`: comportamiento de la aplicación; las instrucciones están comentadas línea por línea.

## Nota
Las tareas se guardan solamente mientras la página permanece abierta; al recargar, la lista vuelve a quedar vacía. Es una versión básica para una práctica introductoria.
